# Fuel Route Planner API

A Django 6.1 API that takes a start and finish location in the USA and returns:

- the driving route (GeoJSON) plus a link to an interactive map of it,
- the most cost-effective places to refuel along the way (500-mile range),
- the total money spent on fuel (10 mpg).

A typical request makes **one** external API call (the OSRM route). Everything else runs locally, and repeated requests are served from cache in about 1 ms.

- **Repository:** https://github.com/ai-mavric/Assignment
- **Demo screen recording:** [screen-recording.mov](https://github.com/ai-mavric/Assignment/releases/download/v1.0/screen-recording.mov) (369 MB, attached to the [v1.0 release](https://github.com/ai-mavric/Assignment/releases/tag/v1.0))

> **Note on data:** the fuel prices file mentioned in the assignment was not received, so
> `data/fuel-prices-for-be-assessment.csv` is a **dummy** file in the same format (OPIS Truckstop ID,
> Truckstop Name, Address, City, State, Rack ID, Retail Price), generated by
> `scripts/make_dummy_fuel_prices.py`: 8,000 stations in random US towns, with prices based on rough
> per-state levels. To use the real file, replace the CSV and run `load_stations` again.

## Quick start

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
python manage.py migrate
python manage.py load_stations   # loads data/fuel-prices-for-be-assessment.csv; downloads Census place data on first run
python manage.py runserver
```

Open http://127.0.0.1:8000/route/map/?start=New%20York,%20NY&finish=Los%20Angeles,%20CA, or import
`fuel-route.postman_collection.json` into Postman.

## API

`POST /api/route/` with `{"start": "...", "finish": "..."}`, or `GET /api/route/?start=...&finish=...`

Locations can be `"City, ST"`, `"City, State"`, a full US address, or `"lat,lon"`.

```jsonc
{
  "map_url": "http://127.0.0.1:8000/route/map/?start=New+York%2C+NY&finish=Los+Angeles%2C+CA",
  "start":  {"query": "New York, NY", "label": "New York city, NY", "lat": 40.66, "lon": -73.93, "geocoded_by": "gazetteer"},
  "finish": {...},
  "route":  {"distance_miles": 2810.4, "duration_hours": 42.1, "geometry": {"type": "LineString", "coordinates": [[lon, lat], ...]}},
  "fuel_stops": [
    {"stop_number": 1, "name": "...", "address": "...", "city": "...", "state": "PA", "lat": 41.0, "lon": -76.9,
     "price_per_gallon": 2.9, "route_mile": 179.3, "distance_from_route_miles": 3.4,
     "fuel_on_arrival_gallons": 31.7, "gallons_purchased": 18.3, "cost": 53.0}
  ],
  "summary": {"total_fuel_cost": 700.69, "gallons_purchased": 238.8, "number_of_stops": 8,
              "total_distance_miles": 2887.7, "total_fuel_used_gallons": 288.8, "vehicle_range_miles": 500, "vehicle_mpg": 10,
              "assumptions": "..."},
  "meta": {"routing_api_calls": 1, "geocoding_api_calls": 0, "stations_considered": 339, "cached": false, "elapsed_ms": 1138.3}
}
```

Errors: `400` for invalid or non-US input, `422` when no route or no feasible fuel plan exists, `502` when the upstream API is down.

`GET /route/map/?start=...&finish=...` renders the same plan on a Leaflet/OpenStreetMap map. It reuses the cached plan, so opening the map does not call the routing API again.

## How it works

1. **Geocoding without API calls.** `load_places` loads roughly 59k US city and town centroids from the public-domain US Census Gazetteer. `"City, ST"` inputs are resolved from that table. Only free-form addresses fall back to Nominatim (OpenStreetMap), and those results are cached.
2. **One routing call.** OSRM (`router.project-osrm.org`, free, no API key) returns the full route geometry.
3. **Stations near the route.** Fuel stations are geocoded once, at import time, to their city centroid. They are kept in memory as numpy arrays. The route is resampled every 0.5 mi and put into a SciPy KD-tree, so every station within 10 mi of the road is found and projected to a mile marker in a few milliseconds.
4. **Optimal fuel stops** (`routing/services/optimizer.py`). This uses the classic greedy solution to the "gas station problem":
   - If a cheaper station is within range, buy just enough fuel to reach it.
   - Otherwise, if the destination is within range, buy just enough to finish.
   - Otherwise, fill up and go to the cheapest station within range.

   The detour to and from each station counts against range and fuel use. Prices within `FUEL_PRICE_TOLERANCE` ($0.05) are treated as equal. That avoids stops that top up a couple of gallons to save pennies, and in practice it also lowers the total, because fewer detours are driven. A stop never
   buys less than `MIN_PURCHASE_GALLONS` (5 gal): such a purchase is skipped if the tank already covers the next leg, or rounded up otherwise.
5. **Map.** The route geometry is simplified with Ramer–Douglas–Peucker so the response stays small.

### Assumptions

- The vehicle starts with a full tank (500 mi). `total_fuel_cost` is the money spent at fuel stops, so a trip under 500 miles costs $0.
- A station's position is its city centroid, because the CSV has no coordinates. Cities the Gazetteer doesn't know can be geocoded once with `load_stations --nominatim`, which caches results in `data/nominatim_cache.json`.
- Settings such as range, mpg, maximum detour and price tolerance are in `config/settings.py`.
